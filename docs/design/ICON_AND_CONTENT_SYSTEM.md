# Icon and Content System

## Icons

The current Stitch export uses Material Symbols.

Rules:
- Prefer one consistent icon family.
- Use icons to reinforce meaning, never as the only label for important actions.
- Avoid AI-specific sparkle/robot/brain iconography.
- Use semantic financial icons: account, rupee/money, document, calendar, goal, loan, shield, alert, search, settings.
- Icon size must follow the component scale; do not mix arbitrary sizes.

## Trust/status icons

Pair status icon + text:
- Verified
- Calculated
- Needs Review
- Official Source (only when actually official)

Do not use green as a synonym for "truth" unless the underlying status warrants it.

## Content rules

Every important surface should answer:
1. What happened?
2. Why does it matter?
3. What can I do?

Prefer short sentences.

Avoid unexplained:
- CAGR
- liquidity
- liability
- allocation
- reconciliation
- corpus

If technical terminology is required, explain it inline.

## Numbers

Use Indian number formatting where applicable:
- ₹
- lakh
- crore
- tabular financial numerals

Never fabricate a number just to make a card look complete.
